# Chinese Night Lights Practice

A mobile-friendly practice app for the Chinese driving-test night lighting commands.
The current audio build uses a picture-checklist-aligned WAV bundle for the 13 rule prompts plus separate exam start/end prompts.

## Modes

- Exam Simulator: fixed opening command, 6 separate random prompts, fixed closing command, instant fail on any wrong answer.
- Practice Test: all commands in order for learning.
- Mistake Bank: saves wrong answers locally in the browser and lets you drill them later.
- Learn and Review: study the Chinese, pinyin, meaning clues, and required car-light action.
